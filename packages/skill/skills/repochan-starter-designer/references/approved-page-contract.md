# Gate-2 Approved Page Input Contract

Starter productization only accepts a specific project website that has been implemented and human-approved. The minimum input includes:

- The Gate 2 approval conclusion and the corresponding actual page, not just a design mockup;
- Complete runnable source code, routes, locales, interactions, motion, and reduced-motion implementation;
- Canonical desktop/mobile screenshots and run instructions;
- The project copy, URL, theme tokens, and character assets actually consumed by the page;
- Original production assets and their provenance; for complex baked images that need migration, clarify which identity information should be downsampled in the reference image;
- Build, viewport, locale, keyboard, overflow, link, and accessibility results;
- Browser differences or known limitations that still require human confirmation.

Any of the following should be returned to the Web Designer:

- Gate 2 is not approved, or the approval target is not the actual page;
- Key sections are still placeholders or undesigned style extrapolations;
- Productization requires adding new sections, changing the information architecture, or redoing the art direction;
- Mobile, locale, interaction, or reduced-motion have not yet been implemented.

Productization may aggregate replaceable values and add migration references, but must not alter the deliverable's core composition and identity under the pretext of "generalization."
