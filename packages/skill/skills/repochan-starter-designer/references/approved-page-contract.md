# Gate-2 approved page 输入合同

Starter 产品化只接受已经实现并经人类批准的具体项目网站。最低输入包括：

- Gate 2 批准结论与对应的实际页面，而不只是设计图；
- 完整可运行源码、路由、locale、交互、动效与 reduced-motion 实现；
- canonical desktop/mobile 截图和运行方式；
- 页面实际消费的项目文案、URL、主题 token 与角色资产；
- 原始生产资产及其来源；复杂烘焙图若要迁移，需明确哪些身份信息应在参考图中降采样；
- build、viewport、locale、键盘、overflow、链接和可访问性结果；
- 浏览器差异或仍需人工确认的已知限制。

以下任一情况都应退回 Web Designer：

- Gate 2 未批准，或批准对象不是实际页面；
- 关键 section 仍是占位或未经设计的样式外推；
- 产品化必须新增 section、改变信息架构或重做艺术方向；
- 移动端、locale、交互或 reduced-motion 尚未实现。

产品化可以聚合可替换值并增加迁移参考，但不能借“通用化”改变成品的核心构图和身份。
