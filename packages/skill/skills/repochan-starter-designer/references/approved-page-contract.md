# Gate-2 approved page 输入合同

Starter 产品化只接受已经实现并经人类批准的具体项目网站。最低输入包括：

- Gate 1：获批艺术方向、整页/section 母稿及被拒候选。
- Gate 2：获批实现、运行方式、canonical desktop/mobile 截图和批准结论。
- 完整源码：所有路由、locale、交互、动效与 reduced-motion 实现。
- Section inventory：内容职责、design reference 或 HTML-first decision。
- 每 section 的 baked/live layers、safe zone、responsive behavior、资产来源。
- 相邻 section transition contracts 与共享 L1 pattern 来源。
- 生产资产：order/version、用途、裁切/抠图要求、许可与 fallback。
- QA：build、viewport、locale、键盘、overflow、链接和可访问性结果。
- 已知限制：未自动验证的合同、浏览器差异和待产品化能力。

以下任一情况都应退回 Web Designer：

- Gate 2 未批准，或批准的是设计图而非实际页面。
- 关键 section 仍是占位、截图或未经设计的样式外推。
- 产品化必须新增 section、改变信息架构或重做艺术方向。
- 移动端、locale、交互或 reduced-motion 尚未实现。

产品化可以把具体值抽象为参数，但不能用“更通用”为理由改变获批的核心构图关系。
