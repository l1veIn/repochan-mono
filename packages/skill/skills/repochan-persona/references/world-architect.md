# 世界架构师（World Architect）

从仓库信号 + 用户意图出发，在 `projectWeight` 约束下，构建一个**体量匹配**的世界。

- 确定世界的名称、**核心规则**（1-2 句话——让这个世界与众不同的唯一法则或条件）和氛围。
- 思考：*"如果这个仓库是一个你可以走进去的地方，它会是什么样的地方？"*——但**这个"地方"的规模必须与 projectWeight 匹配**：轻量项目是一个房间/角落，重量项目可以是一个完整世界。
- 世界应该是仓库情感氛围的自然延伸——它的节奏、它的价值观、它那些不成文的规则。
- 确定角色在这个世界中所处的**角色定位**——他们与世界的关系是什么，他们与环境之间存在什么张力或和谐。

#### 世界类型去重（避免"档案馆/走廊/图书馆"模板化）

实测发现，面对"数据处理型"仓库（搜索、索引、数据库、CLI 工具），World Architect 极易退回同一个"安静的档案/索引空间"模板——走廊、书架、悬浮节点、暖光、精确氛围。这导致多个项目的世界在空间结构、角色姿态和氛围上高度雷同。

**硬性要求：在确定世界类型前，必须先列出 2-3 个候选世界原型并各给 1 句理由，然后选择最贴切且与典型"档案/索引"模板差异最大的那个。** 如果最终仍选档案/索引类，必须在 `sourceSignals` 里明确说明为什么其他类型不合适。

世界原型参考菜单（非穷举，鼓励原创）：

| 原型 | 空间特征 | 适合的仓库类型 |
|---|---|---|
| 居所/工坊型 | 温馨日常空间，有生活气息 | 工具链、编辑器、starter |
| 公共场所型 | 市集、港口、剧院、车站——开放、有流动感 | 网关、代理、消息队列 |
| 自然生态型 | 花园、森林、河流系统——有机、生长性 | 框架、生态项目 |
| 交通/网络型 | 道路、航线、电网——连接、流动、分发 | 路由、CDN、搜索 |
| 档案/索引型 | 图书馆、档案馆、回廊——精确、有序 **⚠️ 已过度使用，除非有强信号否则避免** | 索引、文档系统 |
| 异世界/概念型 | 晶体殿堂、数据虚空、阈界——高概念、非日常 | 数据库、基础设施 |
| 城市街区型 | 街道、社区、建筑——日常但有层次 | 应用、平台 |
| 剧场/表演型 | 舞台、观众席、后台——表演、展示 | UI 框架、可视化 |
| 实验室/工坊型 | 实验台、原型机——创造、迭代 | 实验/研究项目 |

**氛围多样性提醒**：不要所有世界都是"安静、精确、暖光"。根据项目气质，世界可以是热闹的（市集）、动态的（交通网络）、有机生长的（花园）、甚至略带危险感的（风暴带）。

#### 视觉风格建议（World Architect → Character Designer 的交接）

World Architect 对世界的氛围、光线、节奏、情感质地有最深理解，因此由它提出视觉风格建议供 Character Designer 参考。**这不是一个持久化字段**——它只存在于世界描述的输出文本中，作为 Character Designer 确定 `artStyle` 的上游输入。

在世界设定输出后，附一段**视觉风格建议**：
- 基于世界的视觉气质，提出 **2-3 个**适合的二次元风格方向，每个含风格名 + 1 句理由（源自世界/仓库信号）。
- 艺术风格有多个正交维度，建议时可以从不同维度组合（一个风格可以同时是"某技法 + 某氛围 + 某设计运动"）：
  - **绘画技法维度**：厚涂/油画（可见笔触/浓郁光影）、水彩（透明/晕染/留白）、赛璐璐（干净线条+平涂色块）、像素艺术（限制色板/颗粒感）
  - **主题氛围维度**：赛博朋克（霓虹/暗色/未来都市）、蒸汽朋克（齿轮/蒸汽/维多利亚）、太阳朋克（自然+科技/明亮/可持续）、暗黑哥特（暗色/繁复/神秘）
  - **设计运动维度**：新粗野主义（粗粝/原始/高对比）、构成主义（几何/功能主义/宣传感）、孟菲斯（彩色几何/撞色/俏皮）、解构主义（破碎/错位/不规则）、故障美学（数字失真/色差/像素错位）、装饰艺术（对称/华丽/金属质感）、极简主义（纯色块/几何简化/留白）
  - **文化地域维度**：吉卜力风（日式水彩手绘/温暖）、浮世绘（日式木版画）、水墨/墨绘（中式水墨/意境）
- 建议要**源自项目**——一个高性能缓存框架（速度/内存/工业感）可能建议"赛博朋克 neon + 故障美学"或"构成主义 + 厚涂"；一个 Markdown 编辑器（写作/优雅）可能建议"吉卜力水彩"或"装饰艺术 + 赛璐璐"。鼓励**跨维度组合**产生独特风格。
