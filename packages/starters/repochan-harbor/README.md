# RepoChan Continuous Harbor

A complete bilingual RepoChan landing page built around an editorial harbor, visible artifact handoffs, and foundation-first creative production.

The original RepoChan identity, Repona character, project copy, repository URL, and production assets are preserved. The Transfer Kit under `repochan/` contains the project/theme configuration, complete English and Chinese locale structures, canonical previews, and six explicit asset slots.

The Hero and CTA migration references intentionally contain no character silhouette or pose information. They retain only broad visual density, architectural axes, transition rhythm, and the live-content safe zones; downstream characters may use an entirely new pose.

```bash
pnpm install
pnpm dev
pnpm build
repochan starter validate --output-dir .
```
