# MarkText Midnight Editorial

A complete MarkText landing page combining a midnight Art Deco hero, paper-texture sections, product workflow, and a real editor/theme gallery.

The original MarkText identity, character, generated patterns, and product screenshots are preserved. The Transfer Kit lives under `repochan/`: project/theme configuration, complete English and Chinese locale structures, desktop/mobile previews, generated visual slots, and scalar gallery screenshot slots.

```bash
pnpm install
pnpm dev
pnpm build
```
