# Redis Signal Relay

A complete Redis landing page with kinetic cel-shaded character art, a shared seamless relay pattern, and multi-section product storytelling.

The original Redis identity and source assets are preserved. The Transfer Kit lives under `repochan/`: project/theme configuration, complete English and Chinese locale structures, desktop/mobile previews, and the `hero-composite` plus `pattern-tile` migration slots.

```bash
pnpm install
pnpm dev
pnpm build
```
