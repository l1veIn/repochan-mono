# Registry Modular

A seven-section Astro starter productized from an approved modular registry page. The Hero keeps one replaceable visual slot; Nav, Capabilities, Workflow, Proof, CTA, Footer, transitions, and interactions remain live HTML/CSS/SVG.

All project content, theme values, and asset state live under `repochan/`. The fallback artwork is identity-neutral, so a pulled starter builds before any project-specific order is created.

```bash
pnpm install
pnpm build
```
