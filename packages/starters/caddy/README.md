# Caddy Gatehouse

A complete Caddy landing page built around automatic HTTPS, architectural gateways, protective motifs, and ordered section transitions.

The original Caddy identity and source artwork are preserved. The Transfer Kit lives under `repochan/`: project/theme configuration, complete English and Chinese locale structures, desktop/mobile previews, and the `hero-composite` migration slot.

```bash
pnpm install
pnpm dev
pnpm build
```
