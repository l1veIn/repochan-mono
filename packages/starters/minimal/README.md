# Minimal Hero

RepoChan's default Hero-only Astro starter. It intentionally contains one page composition, one required visual slot, and only the locale fields consumed by that Hero.

All project-specific data lives in `repochan/`. Do not add palette literals to `src/`; run `repochan starter validate --output-dir <site>` from the parent repository to check the complete Starter v1 contract.

```bash
pnpm install
pnpm dev
pnpm build
```
