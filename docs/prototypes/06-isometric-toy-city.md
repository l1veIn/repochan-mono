# 06 · Isometric Toy City（等距玩具城 · 管线沙盘）

| 字段 | 值 |
|------|-----|
| **style ID** | `isometric-toy-city` |
| **类型** | 单页沙盘导览 / 空间探索型产品站 |
| **优先级** | **P0** |
| **情绪轴** | 玩具 · 可理解 · 微缩世界 · 轻松导览 |
| **建议目录名** | `landing-toy-city` |

---

## 1. 定位

整条 RepoChan 流水线做成 **可点击的等距微缩城市**。  
分析塔、人设工坊、画师棚、部署码头——建筑承载功能，角色是城中 chibi 小人。  
**信息架构从「纵向滚动讲故事」变成「地图 + 详情面板」。**

### 与已有方向的差异

| 对比 | 已有 | 本方案 |
|------|------|--------|
| 全部 4 套 | 主要是纵向 section | **空间地图主导** |
| Game Page | 角色档案 UI | 城市系统 UI |
| Scrolly | 时间轴叙事 | 地理导览 |

---

## 2. 视觉系统

### 色板

| Token | 建议 | 用途 |
|-------|------|------|
| `--sky` | `#B8E0F7` | 天空底 |
| `--ground` | `#E8F0E3` | 地面 |
| `--building-a..e` | 品牌五色软化版 | 分区建筑 |
| `--road` | `#D9DDE5` | 路径 |
| `--ink` | `#1E293B` | UI 字 |
| `--panel` | `#FFFFFF` | 侧栏/弹层 |

玩具感：略低饱和、统一软阴影、塑料/积木边缘。

### 字体

- **UI**：圆润无衬线（Nunito / M PLUS Rounded）
- **地名/建筑名**：略粗 display
- **面板正文**：Noto Sans SC

### 布局法则

- **Hero = 鸟瞰全图**（或轴测 30°）
- 建筑热点可点；选中后 **右侧或底部 panel** 显示该阶段说明 + 资产预览
- 连接道路暗示依赖顺序（foundation 在中心，下游放射）
- 移动端：地图可 pinch/横滑；列表模式兜底（建筑列表代替点击）

### 材质

- 等距块面、圆角积木、轻微 AO
- 资产可「放在建筑橱窗」：贴纸店、海报柱、设定集图书馆

---

## 4. 动效与交互

- **签名**：镜头平移/轻 zoom 至建筑；建筑 hover 弹起 4–8px
- **非** 长滚动 pin 剧场（与 Scrolly 划清）
- 路径虚线沿依赖高亮
- **reduced-motion**：无镜头动画；静态图 + 列表导航

---

## 5. 资产与 slot

| Slot | 必要性 | 说明 |
|------|--------|------|
| `city-map` | 必须 | 主等距全图（可一张大 scene 或拼接） |
| `building-icons` | 建议 | 7 个建筑标识 |
| `chibi-walker` | 必须 | 城中小人（chibi sheet 裁切） |
| `panel-thumbs` | 必须 | 各阶段代表资产 |
| `icon` | 必须 | |

可用 `chibi_3x3` / `item_prop_grid` 丰富城市小物件。  
`city-map` 是最大制作风险：可先 CSS/SVG 等距块，后替换生成大图。

---

## 6. 文案语气

- 导览员：`欢迎来到资产城。先从扫描塔开始。`
- 建筑名有趣但可映射产品，避免纯谜语
- **禁忌**：恐怖城市、赛博废土（那是 Glitch OS）

---

## 7. 风险与验收

| 风险 | 缓解 |
|------|------|
| 地图可读性 | 标签始终可读；移动端列表兜底 |
| 制作成本 | Phase 1 用 SVG 积木城，Phase 2 再 bake 插画 |
| 与产品文档脱节 | panel 内必须有真实命令 |

**验收：**

- [ ] 用户能指着地图说出 3 个以上流水线阶段  
- [ ] 不依赖滚动 scrub 也能讲完故事  
- [ ] 与 4 套现网截图并排，IA 明显不同
