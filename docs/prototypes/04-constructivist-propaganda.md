# 04 · Propaganda Machine（构成主义 · 宣传海报站）

| 字段 | 值 |
|------|-----|
| **style ID** | `constructivist-propaganda` |
| **类型** | 竖向海报序列落地页 |
| **优先级** | P2 |
| **情绪轴** | 力量 · 工业 · 口号 · 集体生产美学 |
| **建议目录名** | `landing-constructivist` |

---

## 1. 定位

把 RepoChan 做成 **「创意生产的宣传机器」**。  
全屏海报墙串联流水线；角色被图形化为符号，服务几何与口号，而非美少女立绘中心。

### 与已有方向的差异

| 对比 | 已有 | 本方案 |
|------|------|--------|
| Zine | 手作拼贴、摇滚、纸纹 | 工业几何、有限色、宣传海报 |
| Scrolly | 叙事暗场 | 硬切海报、斜向构图 |
| `caddy` starter | 建筑/HTTPS 构成主义落地 | **RepoChan 自身口号海报墙**（内容与叙事不同） |

> 实现时避免复用 caddy 的 section 文案与「门房/网关」隐喻；只共享设计史语言。

---

## 2. 视觉系统

### 色板（严格有限）

| Token | 色值 | 用途 |
|-------|------|------|
| `--red` | `#C41E3A` 或 `#E11D48` | 主强调、色块 |
| `--black` | `#111111` | 字、几何 |
| `--cream` | `#F3EDE3` | 底 |
| `--gray` | `#6B6B6B` | 次级 |
| 可选 `--blue` | `#1D4ED8` | 仅一张海报点缀 |

禁止彩虹多巴胺满铺（那是 Memphis / Frutiger）。

### 字体

- **口号**：超粗无衬线，极大字号，可竖排中文块
- **拉丁**：Impact 气质或 condensed grotesk（注意授权，可用 Anton / Bebas 替代）
- **正文**：Noto Sans SC Bold/Regular，短句

### 布局法则

- 对角线、圆弧、色块切割、不对称三角
- 每屏 ≈ 一张海报；文字是构图的一部分
- 角色：剪影 / 半调网点 / 几何化处理，可与 `poster-constructivist` 一致

### 材质

- 半调网点、印刷偏移、粗颗粒（轻量）
- 模板：`official/poster-constructivist`

---

## 3. 信息架构

以 **5–7 张全屏海报** 串联：

| 屏 | 口号方向 | 内容 |
|----|----------|------|
| 01 | 总号召 | 给仓库一个灵魂 / 全套品牌资产 |
| 02 | 分析 | 扫描仓库，提取真相 |
| 03 | 访谈/人设 | 角色从协议中站起 |
| 04 | 设定集 | Foundation 即法律 |
| 05 | 画师 | 订单即生产 |
| 06 | 落地页 | 页面也是产物 |
| 07 | CTA | 安装命令 = 入伍/上工 |

页间：硬切或斜向 wipe；底部细进度为几何条，非游戏 HUD。

---

## 4. 动效与交互

- **签名**：斜向 mask 转场；色块硬擦除；口号字逐块砸入
- **避免**：柔和 float、玻璃、丝滑视差
- **reduced-motion**：静态海报叠放，可纵向滚动翻阅

---

## 5. 资产与 slot

| Slot | 必要性 | 说明 |
|------|--------|------|
| `poster-01` … `poster-N` | 核心 | 每屏可一张生成海报，或 CSS 几何 + 单角色符号 |
| `symbol-cutout` | 建议 | 高对比剪影 dig 割 |
| `foundation-halftone` | 可选 | 网点处理后的设定集局部 |
| `icon` | 必须 | 极简章印风 |

生成优先走 `poster-constructivist`；不必 7 张全生成，可用 2–3 张真海报 + CSS 构成屏混合。

---

## 6. 文案语气

- 短口号、祈使句、生产动员：`生产角色。` `交付设定。` `部署页面。`
- 可中英双语叠字（构成主义常见）
- **禁忌**：卖萌、日系轻小说旁白、终端 log 长文

---

## 7. 风险与验收

| 风险 | 缓解 |
|------|------|
| 政治宣传符号过重 | 控制红黑色量；内容锚定开发者工具 |
| 与 caddy 重复 | 文案/隐喻/IA 完全 RepoChan 化 |
| 可读性 | 每屏主口号 ≤ 12 字；说明另设小字区 |

**验收：**

- [ ] 单屏截图即有「海报」完整感  
- [ ] 角色服务几何，而非相反  
- [ ] 与 Zine 并排：工业宣传 vs 摇滚手作
