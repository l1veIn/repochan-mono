# 09 · Anti-Design Chaos Board（反设计 · 混乱布告板）

| 字段 | 值 |
|------|-----|
| **style ID** | `anti-design-chaos` |
| **类型** | 实验性 meme / 社区向落地页 |
| **优先级** | 实验 |
| **情绪轴** | 失控 · 反完美 · 黑客文化 · 故意犯规 |
| **建议目录名** | `landing-anti-design` |

---

## 1. 定位

故意撞色、叠层、旋转截图、参差不齐的字号——像被黑客入侵的 Notion + 打印店事故现场。  
服务 **技术受众与社区传播**，不是主品牌官方默认脸。

### 与 Neo-brutal Zine 的关键差

| Neo-brutal Zine | Anti-Design Chaos |
|-----------------|-------------------|
| 仍有杂志网格与栏目秩序 | **拒绝秩序**，叠到几乎违法 |
| 纸、胶带、摇滚编辑部 | 浏览器默认态、错误 UI、乱贴截图 |
| 生产级可维护 | 实验原型，接受难维护 |

---

## 2. 视觉系统

### 色板

- **故意冲突**：纯红底 + 纯绿字（需提供「可读模式」开关！）
- 默认推荐：**可控混乱**——黄黑警示条 + 默认蓝链接 + 火星文装饰层
- 系统色：`ButtonFace` 灰、Win95 青、选择蓝

### 字体

- 同一页混用 5+ 字体：Times、Comic 替代、Impact、宋体、pixel
- 正文核心路径必须有一条 **可读条**（白底黑字 16px+）

### 布局法则

- 无统一栅格；元素 `rotate(-4deg~12deg)` 随机但写死 seed
- 重叠：截图压标题、贴纸压表单
- Marquee、blink（CSS animation）、进度条 99% 卡死等怀旧 web 1.0 梗
- 滚动可横向 + 纵向双轴（谨慎，移动端关掉横轴）

---

## 3. 信息架构（仍要能买到药）

即使混乱，**信息骨架仍在**：

1. 这是什么（1 句）  
2. 能得到什么（资产列表）  
3. 怎么开始（命令）  
4. 证据（真图乱贴）  
5. 链接（GitHub、docs）  

可用「撕开的便利贴」承载上述 5 点，其余全是噪音装饰。

---

## 4. 动效与交互

- **签名**：错误弹窗（可关）、闪烁、错位 hover
- **必须**：`prefers-reduced-motion` 与 **「给我正常版」** 开关 → 跳转 Swiss 或 Museum 或简化静态
- 不要真的劫持返回/无法关闭（道德与 a11y 底线）

---

## 5. 资产与 slot

| Slot | 必要性 | 说明 |
|------|--------|------|
| `chaos-stickers` | 必须 | 真贴纸乱飞 |
| `screenshot-pile` | 建议 | 终端、PR、订单 JSON 截图 |
| `cutout-tilted` | 必须 | 旋转 dig 割 |
| `banner-wrong` | 可选 | 拉伸变形 banner |

不需新模板；用现有资产 **错误用法** 即风格。

---

## 6. 文案语气

- 杠、梗、自嘲：`我们有设计系统（然后把它扔了）。`
- 可混中英、假 404、假 stack trace
- **核心 CTA 文案必须清醒**

---

## 7. 风险与验收

| 风险 | 缓解 |
|------|------|
| 无障碍灾难 | 可读模式；对比度开关；运动关闭 |
| 品牌损伤 | 不作为默认官网；标明 Experimental |
| 与 Zine 重复 | 更「数字错误」而非「印刷 zine」 |

**验收：**

- [ ] 关闭装饰后 10 秒内能完成「理解 + 复制命令」  
- [ ] 明确标注实验向  
- [ ] 不会被误认为站点坏了（可用顶栏 `EXPERIMENTAL SKIN`）
