# 05 · Solarpunk Orchard（太阳朋克 · 品牌果园）

| 字段 | 值 |
|------|-----|
| **style ID** | `solarpunk-orchard` |
| **类型** | 生长叙事型落地页 |
| **优先级** | P1 |
| **情绪轴** | 温暖 · 生态 · 乐观未来 · 照料与丰收 |
| **建议目录名** | `landing-solarpunk` |

---

## 1. 定位

用 **「种子 → 树 → 果实」** 隐喻：git 仓库长成全套品牌资产。  
仓库酱是园丁 / 果园向导，不是摇滚主唱，也不是水下精灵。

### 与已有方向的差异

| 对比 | 已有 | 本方案 |
|------|------|--------|
| Frutiger Aero | 水下、玻璃、Y2K 气泡 | 陆地果园、日光、植物与太阳能几何 |
| Scrolly | 夜、霓虹、画室 | 日、叶绿、生长 |
| Zine | 纸、冲突色 | 自然材质、陶土与木 |

## 2. 视觉系统

### 色板

| Token | 色值 | 用途 |
|-------|------|------|
| `--sun` | `#F4C15D` | 光、CTA |
| `--leaf` | `#3F8F5A` / `#2F6F4E` | 主绿 |
| `--moss` | `#A8C686` | 浅景 |
| `--clay` | `#C4A574` | 土、卡片 |
| `--sky` | `#87C5E8` | 天空区 |
| `--ink` | `#1F2A24` | 正文 |
| `--paper` | `#F7F3E8` | 底 |

可点缀品牌粉/紫在果实/花朵上，但主调必须是 **日光生态**。

### 字体

- **标题**：温和人文无衬线或软衬线（Fraunces / Source Serif）+ 中文宋/楷点缀标题
- **正文**：Noto Sans SC；舒适行长 60–70 字
- **标签**：小 caps 或等宽仅用于「生长阶段」编号

### 布局法则

- 有机分区：曲线分隔、枝叶 frame，非硬网格暴政
- 中段可用「年轮 / 横截面」时间线
- 角色 dig 割与植物层叠（人在树下、摘果、浇水姿态优先）

### 材质

- 纸质纤维轻纹理、水彩边缘、木刻/risograph 绿感（轻）
- **禁止**：扫描线、重金属摇滚、厚黑 neo-brutal 框（除非果实标签小贴纸）

## 4. 动效与交互

- **签名**：滚动驱动枝叶展开；光影「日轨」缓慢移动；果实 hover 轻晃
- **视差**：远山 / 中树 / 近草三层
- **reduced-motion**：静态全展开插画，无生长动画

---

## 5. 资产与 slot

| Slot | 必要性 | 说明 |
|------|--------|------|
| `hero-scene` | 必须 | 日光果园场景 + 角色（`poster-scene` 向） |
| `cutout-gardener` | 必须 | 园丁姿态 dig 割 |
| `harvest-stickers` | 必须 | 果实化贴纸墙 |
| `foundation-plaque` | 建议 | 设定集如「树的铭牌」 |
| `pattern-leaf` | 可选 | 无缝叶纹 |
| `icon` | 必须 | 叶/日/角色简化标 |

生成 brief 需明确：**自然光、植物、无电子屏堆砌**（与 sealed-scroll 夜工坊区分）。

## 6. 文案语气

- 照料、生长、丰收：`播下一行 git，收成一套品牌。`
- 步骤名：`验土` `育种` `日照` `采摘` `分享`
- **禁忌**：赛博末日、故障、暴力摇滚；也不要纯农牧土味段子盖过产品
