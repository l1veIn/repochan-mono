# 02 · Memphis Playground（孟菲斯 · 几何游乐场）

| 字段 | 值 |
|------|-----|
| **style ID** | `memphis-playground` |
| **类型** | 活泼多 section 产品落地页 |
| **优先级** | P1 |
| **情绪轴** | 俏皮 · 设计史 · 玩具感 · 乐观撞色 |
| **建议目录名** | `landing-memphis` |

---

## 1. 定位

管线每一步是一块 **「玩具几何舞台」**，角色像贴纸被丢进 80 年代后现代形状乐园。  
强调「创意生产可以很好玩」，而非摇滚叛逆或玻璃梦幻。

### 与已有方向的差异

| 对比 | 已有 | 本方案 |
|------|------|--------|
| Neo-brutal Zine | 粗黑边、纸纹、杂志秩序 | 几何色块、无「zine 栏」隐喻、更平面设计史 |
| Frutiger | 柔光、玻璃、水下 | 硬边形状、无 blur、陆地/抽象舞台 |
| Game Page | 暗色 HUD | 亮底、无游戏 UI chrome |

---

## 2. 视觉系统

### 色板（高饱和、可轮换主角色）

| Token | 建议 | 用途 |
|-------|------|------|
| `--ink` | `#1A1A1A` | 文字 |
| `--bg` | `#FFF8F0` 或 `#F0F4FF` | 底 |
| `--pink` | `#FF6B9D` | 形状 A |
| `--cyan` | `#2EE6D6` | 形状 B |
| `--yellow` | `#FFE566` | 形状 C |
| `--violet` | `#8B7CFF` | 形状 D |
| `--coral` | `#FF8A5B` | CTA |

可与仓库酱品牌色（sky/pink/violet/mint/amber）对齐，但 **形状语言优先于品牌五色忠实度**。

### 字体

- **Display**：粗圆或几何无衬线（Fredoka、Nunito Black、或自定义圆角 display）+ 中文圆体/粗黑
- **正文**：Noto Sans SC Medium
- **点缀**：少量手写仅用于标签贴纸，不主导

### 布局法则

- 不对称分割：对角线、拱门框、圆形挖空
- 模块像积木：圆角大、间距松、模块可「倾斜 ±3–6°」
- 角色 dig 割骑在形状边缘（半压在色块上）

### 材质与母题

- 锯齿、半圆、波浪、圆环、三角、点阵
- 平涂为主；选择性「长投影」或 soft 立体阴影（Memphis 立体，非 neo-brutal 硬偏移 8px 黑影）
- **禁止**：和纸胶带、报纸剪贴、扫描线（那些属于 Zine / Glitch）

---

## 3. 信息架构

1. **Shape Nav** — 顶部用小几何图标代替普通链接
2. **Hero Stage** — 中央几何舞台 + 角色 dig 割 + 短 headline + 双 CTA
3. **Pipeline Blocks** — 6 步 = 6 块不同形状的「积木」，横滑或错落网格
4. **Asset Carousel** — 贴纸/状态/图标在圆形轨道或转盘上
5. **Play Rules** — 三列「怎么玩」：装 CLI → 跑 skill → 拿走资产
6. **CTA Confetti** — 大色块收尾 + 复制命令
7. **Footer** — 形状分割线 + locale

---

## 4. 动效与交互

- **签名**：形状弹性弹入（spring）；hover 旋转/放大；scroll 时色块轻微重组
- **可选**：点击形状掉落小 confetti（克制）
- **reduced-motion**：无弹跳，形状静态落位

---

## 5. 资产与 slot

| Slot | 必要性 | 说明 |
|------|--------|------|
| `hero-cutout` | 必须 | 透明 dig 割，骑在舞台上 |
| `sticker-grid` | 必须 | 转盘/墙 |
| `memphis-poster` | 建议 | 可用模板 `official/poster-memphis` |
| `pattern-tile` | 可选 | 点阵/几何底纹 |
| `icon` | 必须 | favicon + nav |

管线契合度高：`poster_memphis.yaml` 已存在。

---

## 6. 文案语气

- 轻快、邀请式：`拼出你的品牌。` / `把仓库丢进形状乐园。`
- 步骤名可用动词玩具化：`拆开` `涂色` `贴上` `展览`
- **禁忌**：黑暗赛博、恐怖谷、过度「杂志编辑部」腔

---

## 7. 风险与验收

| 风险 | 缓解 |
|------|------|
| 与 Neo-brutal 撞车 | 禁用粗黑 4px 边 + 硬黑影；改用形状与倾斜 |
| 儿童化过度 | 保持 CLI 命令与真实资产证据 |

**验收：**

- [ ] 并排 Zine 时：一个是「杂志」，一个是「图形游乐场」  
- [ ] 主视觉有明确几何母题（非随机装饰）  
- [ ] `poster-memphis` 生成图能直接进页
