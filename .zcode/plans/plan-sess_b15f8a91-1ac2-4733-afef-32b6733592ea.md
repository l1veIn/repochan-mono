# Plan: CLI starter list/get/pull + 删除 page 指令集 + page-designer skill 重写

## 第一部分：CLI — `repochan starter list|get|pull`，删除 `page` 指令集

### 1.1 新建 `packages/cli/src/commands/starter.ts`

三个函数：

- `runStarterList(cwd, { tag? })` — 调 `listStarters()`，按 `--tag` 过滤，`emitResult`
- `runStarterGet(cwd, id, options)` — `listStarters().find(s => s.id === id)`，`emitResult` 输出完整 starter.json
- `runStarterPull(cwd, { starter?, outputDir?, overwrite? })` — 原 `runPageGenerateProject` 的逻辑搬过来：解析 starter 目录 → `fs.cp` scaffold 到 output dir（默认 `.repochan/web-starter/`），排除 node_modules/dist/.astro/starter.json

### 1.2 `packages/cli/src/index.ts`

**删除** `page <sub>` 命令块（原 lines 130-147）。

**新增** `starter <sub>` 命令块：
```ts
cli.command("starter <sub>", "Landing-page starters")
  .option("--json", "Machine-readable JSON output")
  .option("--tag <tag>", "Filter starter list by tag")
  .option("--output-dir <dir>", "Output directory (pull, default: .repochan/web-starter)")
  .option("--overwrite", "Overwrite existing (pull)")
  .action(async (_p, opts) => {
    const args = cli.args;
    const sub = args[0];
    switch (sub) {
      case "list": return await starter.runStarterList(process.cwd(), opts);
      case "get": return await starter.runStarterGet(process.cwd(), args[1], opts);
      case "pull": return await starter.runStarterPull(process.cwd(), opts);
      default: throw new Error(`Unknown starter subcommand: ${sub}. Use: list | get | pull`);
    }
  });
```

### 1.3 `packages/cli/src/commands/entities.ts`
