## 实施计划(7 步)

### 第 1 步:改进 pattern 模板 prompt(`pattern_2x2.yaml`)

**文件**:`packages/templates/pattern_2x2.yaml`

当前 prompt 虽然要求了纯白 gutter 和可裁切,但生图模型没有精确遵守(加了 "01"/"02" 编号文字、gutter 不够干净)。借鉴 `icon.yaml` 的逐格枚举模式,强化约束:

**prompt_template 改进点**:
- 明确**禁止任何文字、编号、标签**("no numbers, no labels, no text of any kind inside tiles")
- 要求每个 tile **满铺到象限边缘**(bleed to cell edges),不留内边距
- 逐格描述 4 个纹样(参考 icon 模板的 ROW 结构):
  - `TILE 0 (top-left)`: {{pattern_concepts[0]}}
  - `TILE 1 (top-right)`: {{pattern_concepts[1]}}
  - `TILE 2 (bottom-left)`: {{pattern_concepts[2]}}
  - `TILE 3 (bottom-right)`: {{pattern_concepts[3]}}
- 强调 gutter 宽度:"thick pure-white gutters at least 16px wide, completely empty"
- 强调四方连续:"each tile must be a SEAMLESS repeating texture — edges must wrap cleanly"

**constraints 补充**:
- "NO text, numbers, labels, or captions anywhere on the sheet"
- "each tile's texture must bleed fully to its cell boundaries — no internal padding"
- "gutters must be at least 16px wide and completely empty white"

### 第 2 步:重生成 pattern sheet

用改进后的模板重新生图。执行方式由用户在实施阶段决定(通过 agent 跑 `repochan order create-result`,或手动 `repochan image gen`)。

prompt 填充 Chan 的实际值:
- `key_motifs`: 菱形光标印记 / Git DAG 节点 / JSON 字段名 / 版本号标签
- `pattern_concepts`: 4 个 signaturePatterns(菱形+版本号四方连续 / DAG 细线网格 / JSON 等宽条纹 / Mondrian 色块)
- `color_palette`: #6ee7ff #0f172a #a78bfa #f9a8d4

### 第 3 步:纹理裁剪落地(image-edit + CLI)

**文件**:`packages/image-edit/src/slicing.ts` + `packages/cli/src/commands/image.ts`

当前 `sliceImage` 只返回坐标元数据,不生成文件。新增 `sliceGridToFiles(imagePath, rows, cols, outDir, options?)`:
- 复用 `computeTileCells` 算坐标
- **关键改进:支持 `padding` 参数**——从每个格子边缘内缩 N 像素裁切,避开 gutter 白线。比如 512px 格子内缩 8px,裁出 496×496 的干净纹理
- 用 `loadImglySharp()`(imgly 自带的 sharp 0.32)裁剪并写出 `tile-0.png` … `tile-3.png`
- 返回每个 tile 的路径 + 尺寸 + 实际裁剪区域

**CLI 接线**:`runImageEditSlice` 增加 `--out <dir>` 和 `--padding <px>` 参数。有 `--out` 时调用 `sliceGridToFiles` 落盘;无 `--out` 时保持当前行为(只输出 JSON 坐标)。

**验证**:`pnpm --filter @repochan/image-edit test`(给 sliceGridToFiles 加单元测试)

### 第 4 步:执行裁剪,产出 4 个 texture tile

```bash
repochan image edit slice <regenerated-pattern.png> \
  --rows 2 --cols 2 --padding 8 \
  --out repochan-page/public/textures/
```

产出:
- `tile-0.png` — 菱形光标+版本号四方连续(hero 背景)
- `tile-1.png` — Git DAG 细线网格(边框/分割线)
- `tile-2.png` — JSON 字段名条纹(社交卡片侧边)
- `tile-3.png` — Mondrian 色块(周边/CTA 底纹)

同时把角色资产(foundation/poster/banner/icon/chibi)拷贝到 `repochan-page/public/assets/`。

### 第 5 步:重写 `repochan-page` 为构成主义模板

**完全重做**。技术栈保持 Astro + Tailwind 3。

#### 5a. persona → design tokens(`src/config/site.ts`,新建)

build-time `readFileSync` 读根目录 `.repochan/persona/current.json`:
```ts
// 解析后输出
{
  persona: { name, nameZh, tagline: catchphrase, personality },
  palette: {
    primary:   "#6ee7ff",   // mainColor
    base:      "#0f172a",   // secondaryColor (dark)
    accent1:   "#a78bfa",   // accentColors[0]
    accent2:   "#f9a8d4",   // accentColors[1]
    // RGB 三通道(支持 rgb(var(--x-rgb) / 0.4) 透明度语法)
  },
  textures: [
    { src: "/textures/tile-0.png", usage: "hero-bg",   desc: signaturePatterns[0] },
    { src: "/textures/tile-1.png", usage: "divider",   desc: signaturePatterns[1] },
    { src: "/textures/tile-2.png", usage: "sideband",  desc: signaturePatterns[2] },
    { src: "/textures/tile-3.png", usage: "cta-bg",    desc: signaturePatterns[3] },
  ],
  motifs: keyMotifs,        // 菱形/DAG/JSON/版本号
  artStyle: "赛璐璐 + 构成主义",
  constructivist: {          // 从 artStyle 派生的 UI 语言
    radius: "0px",           // 硬边,无圆角
    lineWeight: "3px",       // 粗黑分割线
    lineColor: "#0f172a",
    gridGap: "2px",          // Mondrian 紧密分割
  },
}
```
fallback:persona 读不到时用 Chan 硬编码值。

#### 5b. Layout 注入(`src/layouts/SiteLayout.astro`,重写)

- frontmatter `import { site } from "../config/site"`
- `<head>` 内 `<style is:inline set:html>` 注入 `:root { --c-primary: ...; --c-accent-1-rgb: ...; --texture-hero: url(...); --radius: 0px; ... }`

#### 5c. 构成主义视觉系统(`src/styles/global.css`,重写)

**"大胆配色 + 纹理"的核心落地**:
```css

body { background: var(--c-base); color: var(--c-primary); }

/* 硬边色块 */

  border-radius: var(--radius);
  border: var(--construct-line) solid var(--construct-line-color);
}

/* 纹理叠加:白底纹理用 multiply 叠到色块上 */

  background-size: 256px;
  background-repeat: repeat;
  mix-blend-mode: multiply;
  opacity: 0.12;
}
/* 纹理叠加:透明纹理直接平铺 */

  background-image: var(--texture-divider);
  background-size: 128px;
  background-repeat: repeat;
}
```
